# Known Limitations

- This repository is a research resource rather than a production software package.
- No CAD, PCB, manufacturing, firmware implementation, or hardware-dependent control module is distributed.
- Model weights and training data are not duplicated from IEEE DataPort.
- The included example inspects an already downloaded package; it does not download data.
- Hardware connection, reconnection, safety behavior, and closed-loop operation are not automatically validated by this repository.
- Contact localization in the released evaluation uses five prescribed anchors; this repository does not claim arbitrary continuous-surface localization.
- No one-command end-to-end reproduction of the physical experiments is claimed.
