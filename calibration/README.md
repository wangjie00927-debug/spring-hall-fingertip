# Calibration Resources

Calibration data and result tables are hosted on IEEE DataPort rather than duplicated in this repository.

Relevant DataPort modules include:

- `01_FORCE_CONTACT_CALIBRATION` for force/location summaries and the frozen trial split;
- `03_CROSS_INSTANCE_CALIBRATION` for A1/A2 calibration-reuse result tables; and
- `07_MODEL_TRAINING/data` for the anonymized training feature cache and split manifest.

This repository documents how to locate and interpret released calibration evidence. It does not distribute a complete calibration implementation. Use complete-trial identifiers and the supplied split manifest when analyzing the released data.
