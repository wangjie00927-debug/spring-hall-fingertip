# Hardware Scope

The already disclosed system-level fingertip architecture contains:

- a fingertip housing and load-transfer path;
- an excitation coil;
- a titanium-alloy spring;
- a flux-guiding sleeve;
- a protection ring and support structure; and
- four MLX90393 tri-axis Hall sensors arranged on an annular PCB.

The repository provides architecture-level documentation only. No CAD, PCB layout, dimensions, manufacturing files, circuit-design source, or magnetic-path implementation source is distributed in this release.
